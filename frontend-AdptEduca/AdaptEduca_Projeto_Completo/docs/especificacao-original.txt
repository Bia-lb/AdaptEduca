# Desenvolvimento do Front-end da Plataforma AdaptEduca

Vou enviar uma sequência de prints contendo o layout completo do meu projeto. Sua tarefa é analisar cuidadosamente todas as imagens e recriar o site da forma mais fiel possível, utilizando exclusivamente HTML5, CSS3 e JavaScript puro.

## Regra principal

Todas as páginas, telas, modais, menus, componentes, estados e variações visuais apresentados nos prints enviados devem ser desenvolvidos.

Não implemente apenas as páginas citadas neste documento. Os prints são a principal referência do projeto e todas as telas que aparecerem neles fazem parte obrigatória da entrega.

Nenhuma página mostrada nas imagens poderá ser ignorada, resumida, substituída por uma tela genérica ou deixada apenas como demonstração.

Caso os prints apresentem páginas ou funcionalidades que não estejam descritas textualmente neste documento, elas também deverão ser implementadas seguindo fielmente o layout apresentado.

Antes de iniciar o desenvolvimento:

1. Analise todos os prints enviados.
2. Identifique todas as páginas existentes.
3. Identifique menus, submenus, dashboards, formulários, cards, tabelas, modais, filtros e componentes.
4. Organize a navegação completa entre essas páginas.
5. Desenvolva todas as telas encontradas nas imagens.
6. Garanta que nenhum botão visível nos prints fique sem uma interação correspondente.

O foco desta etapa é desenvolver somente o front-end, deixando toda a estrutura preparada para uma futura integração com PHP e MySQL.
