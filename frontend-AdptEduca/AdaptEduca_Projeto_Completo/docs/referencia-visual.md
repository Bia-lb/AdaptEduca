# Referência visual

O projeto foi construído a partir dos prints fornecidos pelo usuário, incluindo:

- Página inicial e seção de benefícios;
- Demonstração de funcionalidades;
- Planos e preços;
- Login e cadastro;
- Questionário de perfil de aprendizagem;
- Dashboard do aluno;
- Adaptação de conteúdo;
- Dashboard do professor;
- Dashboard do responsável.

Os componentes adicionais seguem a mesma identidade visual para completar a navegação e os requisitos funcionais.
